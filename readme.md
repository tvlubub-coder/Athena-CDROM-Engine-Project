ENGLISH:
The ATHENA CD-ROM ENGINE is a multimedia Engine Editor based on AthenaENV, designed to recreate the experience of old interactive CD-ROMs. It offers tools to create full content, like educational games, digital encyclopedias, cultural catalogs, or training applications.

With this engine, you can put together a project that combines text, images, audio, and video in a navigable interface, similar to what was seen in products like Encarta. The idea is to give the creator an integrated environment to organize content, define navigation routes, create quizzes, interactive menus, and export everything ready for distribution as a virtual CD-ROM.

A typical project can include:

- Multimedia assets (images, sounds, videos).

- Interactive logic and navigation scripts.

- Textual content organized into articles or modules.

- Final output compiled in ISO/CD-ROM format.

PORTUGUÊS: 

O ATHENA CD-ROM ENGINE é um editor e engine multimídia baseado no AthenaENV, projetado para recriar a experiência dos antigos CD-ROMs interativos. Ele oferece ferramentas para criar conteúdo completo, como jogos educativos, enciclopédias digitais, catálogos culturais ou aplicativos de treinamento.

Com este motor, você pode montar um projeto que combine texto, imagens, áudio e vídeo em uma interface navegável, parecida com o que se via em produtos como o Encarta. A ideia é oferecer ao criador um ambiente integrado para organizar conteúdos, definir rotas de navegação, criar quizzes, menus interativos e exportar tudo pronto para distribuição como um CD-ROM virtual.

Um projeto típico pode incluir:

- Recursos multimídia (imagens, sons, vídeos).

- Lógica interativa e scripts de navegação.

- Conteúdos textuais organizados em artigos ou módulos.

- Saída final compilada em formato ISO/CD-ROM.
